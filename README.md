PDF文档问答系统

项目介绍
这是一个基于Streamlit和LangChain的PDF文档问答系统，允许用户上传PDF文档并进行问答。系统通过Ollama进行语言模型推理，提供文档内容的检索和回答。

功能特点
PDF上传与处理: 用户可以上传PDF文档，系统进行文本提取和嵌入处理。

问答界面: 提供聊天界面，用户可以输入问题并获得基于文档内容的答案。

会话管理: 支持创建、切换和清空不同会话。

语言模型推理: 如果文档中没有相关内容，系统使用语言模型进行推理回答。


## 环境要求

- Python 3.8+
- Streamlit
- LangChain
- Ollama
- 以及其他相关依赖
